# To-Do List Management System

A simple terminal-based To-Do List application built with Python fundamentals only (no OOP, no external libraries).

## Features
- Add Task
- Show Tasks
- Search Task
- Mark Task as Done
- Remove Task
- Exit

## Error Handling
- Non-numeric or out-of-range menu input
- Empty task names
- Searching, removing, or marking a task that does not exist

## How to Run
python todo_app.py
